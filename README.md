## 🚀 Featured Work

### [Invoice Data Extraction System](https://github.com/Bilal-03/invoice-extraction)

An intelligent system that automatically extracts structured data from invoice images.

**The Challenge:** Manual invoice processing was creating bottlenecks for companies handling thousands of documents monthly.

**My Approach:**

- Combined multiple techniques: image processing, OCR, pattern recognition, and entity extraction
- Built it as a microservice with REST API
- Packaged everything in Docker for easy deployment

**Outcome:** 84% extraction accuracy across 30+ different invoice formats, ~4s processing time
